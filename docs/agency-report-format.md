# 営業代行会社のアポイント報告の様式（CSV）

営業代行会社からアポイントの報告を受け取るときの様式です（#152）。
この様式の CSV か Excel を、DiagnoLeads の「リード → インポート → 代行会社のアポレポートを取り込む」で読み込みます。

- 様式のファイルは、取り込み画面の「様式（CSV）をダウンロード」から取得できます。
- 1行が1件のアポイントです。1行目は列名にします。
- 文字コードは UTF-8 にします。Excel（.xlsx）のままでも読み込めます。
- 1回に取り込めるのは500行までです。
- 列名が違っていても、取り込むときに画面で列の対応を選び直せます。ただし、毎回の手間を減らすため、この様式で出してください。

## 列

| 列名 | 必須 | 書き方 | 例 |
|---|---|---|---|
| メールアドレス | ※ | 先方担当者のメールアドレス。リードを探すのに使います | yamada@example.co.jp |
| 会社名 | ※ | メールアドレスがないときは会社名でリードを探します（同じ会社名のリードが1件のときだけ） | 架空商事株式会社 |
| 代行会社名 | | 自社の名前 | 架空テレアポ |
| アポ日 | | 年/月/日 | 2026/11/05 |
| 担当者名 | | 先方担当者の氏名 | 山田 太郎 |
| 部署・役職 | | 先方担当者の部署と役職 | 情報システム部 課長 |
| 直通電話 | | 先方担当者の直通番号 | 03-0000-0000 |
| 機種 | | 現在使っている機種・システム | IBM Power 9 |
| 機種の確認 | | 先方に機種を確かめたか：「確認済み」か「未確認」 | 確認済み |
| 保守期限 | | ハードウェアの保守期限：年/月 | 2028/03 |
| 退職予定 | | システムを保守している担当者の退職予定：年/月 | 2027/09 |
| 決裁者の同席 | | 初回商談に決裁者が同席するか：「あり」「なし」「不明」 | あり |
| 関心度 | | 「高」「中」「低」 | 高 |
| 断られた理由 | | 断られた・保留になった理由（自由記述） | 今期は予算がない |
| 備考 | | そのほか、商談で伝えたいこと（自由記述） | 来期予算で検討 |

※ メールアドレスか会社名の、どちらかは必須です。

## 取り込んだあと

- **リードへの結び付け**：メールアドレス（大文字・小文字は区別しません）でリードを探し、なければ会社名で探します。
  - 見つからない行は取り込まず、件数を表示します。代行会社の報告からリードは作りません。
  - 同じ会社名のリードが複数ある行も取り込まず、件数を表示します。
- **あとから取り込んだ場合**：同じリードの報告は、新しい内容で置き換わります。
- **ヒアリング票への事前入力**：機種、保守期限、退職予定、決裁者の同席は、そのリードで新しく作るヒアリング票に「代行聴取」として事前に入ります。
  - Web 診断の回答がある項目は、診断の値が優先されます。
  - 事前入力の値は、商談で確かめるまで「確認済み」になりません。
- **リード詳細**：「代行会社からの引き継ぎ」に、すべての列の内容が表示されます。
- **読み取れない値**：日付の形が違うなどで読み取れないセルは、その欄を空にして取り込みます。読み取れなかったセルの数は、取り込む前に画面に表示されます。

## 個人情報

担当者名・直通番号などの個人情報を保存します（2026-10-21 オーナー決定）。
