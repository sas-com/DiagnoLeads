# DiagnoLeads ユーザーガイド

利用者向けの説明の正本は、**管理画面のヘルプ**です（決定 `2026-10-28-in-app-help`、Epic #877）。この文書には操作の説明を書きません。画面と別の場所に置いた説明は、画面の変更に置いていかれるためです。

## ヘルプの開き方

| 入口 | 開くもの |
|------|---------|
| ヘッダーの「この画面の使い方」 | 表示中の画面の使い方（横のパネル）。記事の無い画面では「ヘルプ」のリンクになる |
| ユーザーメニューの「ヘルプ」、または `/ja/help` | ヘルプセンター：目次（業務の流れ・画面の使い方・設定の使い方・用語集）と検索 |
| ダッシュボードの「はじめに設定すること」「はじめにやること」 | 役割ごとの初回のチェックリスト。各項目から設定の画面とヘルプの記事へ移れる |

## ヘルプを直すとき（開発者向け）

- 記事は `lib/features/help/content/` に型付きのデータで置く。Markdown や HTML は使わない
- 画面を変える PR で、その画面の記事も一緒に直す（`.claude/rules/help.md`）。管理画面のページを足したときに記事が無いと、`bunx vitest run test/unit/features/help` が落ちる
- リポジトリは公開なので、社外秘（取引先名・単価・営業の手引きの本文）は書かない
