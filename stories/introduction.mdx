# DiagnoLeads デザインシステム

管理画面の見た目の決まりと、共通の部品（`components/ui/`）の見本です。画面を作る前に、ここで既存の部品と使い分けを確かめます。

## 管理画面の決まり

管理画面（ログイン後の画面と、ログインなどの認証の画面）は、デジタル庁デザインシステム（DADS）の値とルールに合わせています（決定 `2026-10-24-admin-dads`）。

- **色**：キーカラーは Green。`brand-*` が DADS Green、`gray-*` が DADS Solid Gray になる。値は公式のパッケージ `@digital-go-jp/design-tokens` から参照し、`app/globals.css` の `html:has(.dl-admin)` で当てている
- **コントラスト**：文字は背景と 4.5:1 以上、枠線・アイコンなど文字以外は 3:1 以上。補足の文字は `gray-500` より薄くしない
- **フォーカス**：黒の outline と Yellow の二重の枠。部品ごとに色を変えない
- **文字**：本文は 16px 以上（14px は補足だけ。14px 未満は使わない）。本文の行間は 1.5 以上。強調は太字 700
- **ボタン**：塗りのボタンは1画面に原則1つ。色の違いだけで重要度を示さない。押せる範囲は 44px 以上
- **影と装飾**：影は重なって出る部品（ダイアログ・メニューなど）だけ。ほかは枠線で区切る。グラデーション・発光は使わない

## この Storybook の見方

- **基礎**：色・文字・余白と角丸・フォーカス。見本の値は、画面に当たっている実際の値を読んで出している
- **部品**：`components/ui/` の部品。上のツールバーでライトとダークを切り替えられる。「Accessibility」のパネルで、コントラストなどの自動チェックの結果が見られる

どのストーリーも、管理画面と同じ `.dl-admin` の中で描いています。

## 対象外のもの

- AX の公開サイト（`.ax-site`）と診断ビルダーの色は、管理画面と別の決まり
- AI社員オフィス（`/office`）は、オーナーの指示でこの画面に限り装飾の決まりを外している（決定 `2026-11-12-ai-employees-office`）。オフィスの部品のストーリーは、オフィスのコードが main に入ってから足す
- 機能ごとの部品（`components/features/`）

## ストーリーを足すとき

- 置き場所は `stories/`（アプリのビルドに入らない）。部品は `stories/ui/<部品の名前>.stories.tsx`
- 題は `部品/<部品の名前>`。文言は日本語で、実在の会社や人の名前を使わない
- 部品を足す・変える PR で、ストーリーも一緒に直す
