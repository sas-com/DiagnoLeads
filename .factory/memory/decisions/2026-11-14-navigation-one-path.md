### [UI] 導線を1本にそろえる。入口は出社の画面・フロア案内に5つの場所（未完成は今のページへの扉）・管理画面は残して部屋にそろえる・ダッシュボードは今日に統合（Epic #1161）
- **日付**: 2026-11-14
- **きっかけ**（オーナーの指摘。2026-11-14「システムとしての導線がバラバラです。整理してください」）: 最初の画面が4つ（出社の画面・オフィスのページ・ダッシュボード・今日）あった。出社の画面で入れる部屋は2つで、ほかの仕事へは管理画面のサイドメニューへ乗り換えるしかなかった。部屋から開いたページから、出社の画面へ戻る入口が無かった
- **決定**（オーナーの判断。同日、3点を確かめた。どれもこちらの推奨）:
  - 管理画面（通常の表示）は**残して、部屋にそろえる**。一括の操作・取り込み・スマホ・読み上げのため。サイドメニューの並びと名前を部屋に合わせる（#1163）
  - ダッシュボードと今日は**今日に統合する**。ダッシュボードはメニューから外し、今日が社長のデスクの中身になる（#1164）
  - 中身がまだ無い部屋も**フロア案内に全部出し、今のページを開く扉にする**（#1162）
- **形**（`office-rooms.ts` の `FLOOR_PLACES`・`PLACE_KEYS`・`DOOR_PAGES`）:

  | 鍵 | 場所 | 今 |
  |---|---|---|
  | 1 | 社長のデスク | 扉 → `/today` |
  | 2 | マーケティング室 | 部屋（リード） |
  | 3 | 営業フロア | 扉 → `/deals` |
  | 4 | 開発室 | 扉 → `/deals?kind=survey`（現行調査の商談） |
  | 5 | 総務・受付 | 部屋（今日の期限） |

- **ルール**:
  - 入口は出社の画面1つ。管理画面のどのページからも、ロゴで出社の画面のフロアへ1回で戻る（幅 768px 以上。#1169、決定 `2026-11-14-concept-and-flow`）。はじめはヘッダーに「出社する」を足していたが、ロゴが出社の画面を開くようになり、入口が2つになるので外した
  - 扉の行き先は、この表の決まったパスだけ。部屋ができたら、その場所を `OFFICE_ROOMS` に移し、扉から外す。鍵の数字は変えない
  - 扉を開くと、出社の画面を閉じてからページへ移る（部屋の中のリンクと同じ）
- **却下案**:
  - 開発室を商談の「現状把握・提案」の段に絞る：商談の画面に段で絞る仕組みが無く、足すと範囲が広がる。エンジニアの役目（現行システムの調査）に合う「現行調査」の種類の絞り込み（既にある `kind`）にした
  - 管理画面を段階的に無くす：作る量が大きく、スマホと読み上げの代わりが要る（オーナーが残すほうを選んだ）
- **ほかの決定への影響**: `2026-11-13-office-is-the-base` の「まだ決まっていないこと」のうち「従来の一覧の画面を残すか」は、この決定で「残して部屋にそろえる」に決まった
