### [UX] システムのコンセプトと動線：社長として出社し、部屋で AI社員と仕事を進める。場所の役目・ホーム・AI社員の人事・次に作る場所を決めた（Epic #1161）
- **日付**: 2026-11-14
- **きっかけ**: オーナーの指示「一度、システムのコンセプトと動線をしっかり整理しましょう」「決めなければならないことを詰めてください」。同じ日に、別のセッションで導線の整理（Epic #1161、決定 `2026-11-14-navigation-one-path`）が進み、こちらのセッションで 3D（Epic #1146）が進んでいた。全体を1枚にまとめ直し、食い違いを洗い出して、今決める4点を決めた
- **コンセプト**（決定 `2026-11-13-office-is-the-base`・`2026-11-12-ai-employees-office`・`2026-11-13-ai-employee-agents-work-packs` をつないだもの）:
  - **社長として出社し、部屋で AI社員と仕事を進める業務システム**
  - 誰が：組織の人（社長の役）と、採用した AI社員（マーケター・セールス・エンジニア・バックオフィス）
  - 何を：見込み客を見つけ、商談にし、提案をつくり、期限を守る（価値のリレー）
  - どう進めるか：部屋に入ると、AI社員が実際の数字で報告し、選択肢を出す。決めるのは人
  - 層は3つ：出社の画面（土台。2D と 3D は見せ方の違いで、できることは同じ）・部屋（仕事をする場所）・通常の表示（従来の一覧とフォーム。一括の操作・取り込み・スマホ・読み上げのために残す）
- **動線**（Epic #1161 の形のまま）:
  - 入口は出社の画面1つ。フロアから、数字のキーで5つの場所へ行く：1 社長のデスク・2 マーケティング室・3 営業フロア・4 開発室・5 総務・受付
  - 部屋の中身がまだ無い場所は「扉」（入ると通常の表示のページが開く）。部屋ができたら、扉から部屋へ移す
  - 戻りは Esc で1段ずつ（顧客ファイル → 部屋 → フロア → タイトル → 通常の表示）
  - 研修室・ラウンジ・充電ステーションは、AI社員の状態を表す居場所で、仕事の場所ではない
- **決定**（オーナーの判断。2026-11-14、4点とも選択肢から選んでもらった）:
  1. **社長のデスク（鍵1）と総務・受付（鍵5）の役目**：デスクは「今日」の全体（次の行動・商談予定・今日の活動）を見る場所。総務・受付は、バックオフィスが期限の来たものを1件ずつ渡す場所。今の形のまま、言葉で分ける（#1172）
  2. **ホーム（ロゴ）の動き**：ロゴも出社の画面を開く（幅 768px 以上。タイトルは飛ばしてフロアから）。「ホーム＝出社の画面」で1つにする（#1169）。決定 `2026-11-14-login-lands-on-office` の「ロゴは通常の表示のオフィス」は、これで置き換わる
  3. **AI社員の人事（名前の変更・解雇・作業記録）**：出社の画面の会話（話しかける）の選択肢に足す。解雇は取り消せないので、確認の段を入れる（#1170）。通常の表示のオフィスのページは、読み上げ・スマホのための控えにする
  4. **次に中身を作る場所**：営業フロア（商談）。先に、部屋の型と入れ物の整理（#1142）。そのあと #1171
- **却下案**:
  - 1：「今日」を全部デスクに集めて総務・受付を設定だけにする（総務・受付の部屋の作り直しが要る）／デスクをやめて4部屋にする（PR #1165・#1166 の直しが要る）
  - 2：ロゴは今のまま、ヘッダーの「出社する」を足す（入口が2つ残る）
  - 3：総務・受付に人事の棚を作る／今のまま通常の表示に残す
  - 4：社長のデスクを先に作る（毎日最初に開く場所で効果は早いが、価値のリレーの順を優先した）／部屋より先に 3D を仕上げる
- **あとで決めること**（決まるまで、右の前提で進める）:
  - 社長のデスクをフロアの絵（2D・3D）に置くか：**置く**前提。デスクの部屋を作るときに決める
  - 開発室の部屋の中身：扉は「現行調査の商談」（決定 `2026-11-14-navigation-one-path`）。部屋は**ヒアリングと提案の準備**の前提。開発室の部屋を作るときに決める
  - 研修室の使い方：**AI社員の居場所だけ**の前提（営業の手引きは総務・受付の設定の下）。AI社員が手引きを読んで働く仕組み（#1114）を作るときに決める
  - 呼び名：部屋の中は「見込み客」、通常の表示は「リード」のまま。用語の表の案を作ってオーナーに見てもらう（#1172）
  - 幅 768px 未満の入口：**通常の表示を入口**にする前提。スマホ向けの出社の画面を作るときに決める
- **順番**: PR #1165（フロア案内に5つの場所）→ PR #1166（サイドメニュー）→ #1164（ダッシュボードを今日に統合）→ #1169・#1170・#1172 → #1142 → #1171。3D（Epic #1146）は並行して進める
- **ルール**:
  - 場所・画面・入口を足す・変えるときは、この決定の「動線」と「あとで決めること」に照らす。食い違うなら、先にオーナーに確かめる
  - 新しい部屋の鍵の数字は、今の5つ（1〜5）を変えずに足す
  - 複数のセッションが同じ画面（`office-immersive.tsx`・サイドメニュー・利用ガイドのオフィスの記事）を触るので、着手の前に Epic #1161 の順番と open な PR を確かめる
