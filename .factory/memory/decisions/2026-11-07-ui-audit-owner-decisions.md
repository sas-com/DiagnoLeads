### [UI] ui-audit の未決の4点：画像の節はすべての画面、ダークモードの文字の色は3段階、法務と情報システム部門に確かめる（#930）
- **日付**: 2026-11-07
- **決定**（オーナー判断。選択肢と推奨を示して聞いた）:
  1. **「画像」の節**：すべての画面に当てる（推奨は「新しい公開ページだけ」だったが、オーナーは「すべての画面」を選んだ）。既存の AX の公開サイトの画像（コラムの題の画像など、SNS で共有するためのものを含む）は、スキルの対象の表で「配置はそのまま」とした AX の公開サイトの扱い（[2026-10-11-ax-diagnosis-v2](./2026-10-11-ax-diagnosis-v2.md) のデザインに合わせるため）とぶつかるので、変える前に毎回オーナーに確かめる。組織が作った・設定した画像（DB のデータ）には触らない。Payload の CMS 管理画面にも、この節だけは当てる（[2026-11-01-ui-audit-skill](./2026-11-01-ui-audit-skill.md) の「Payload の `/admin` は対象外」を、画像の節に限って変える。その決定はほかの点ではそのまま有効）
  2. **管理画面のダークモードの文字の色**：3段階を決める（推奨は「今の下限だけ」だったが、オーナーは「3段階を決める」を選んだ）。値は DADS の Solid Gray から、主に使う面（`gray-900`・`gray-800`・`gray-700`）に対するコントラストで決めた
     - 主 `gray-50`（#f2f2f2）、補足 `gray-200`（#cccccc）、控えめ `gray-300`（#b3b3b3）
     - `gray-700` の面の上では、控えめも `gray-200` 以上
     - `gray-100`（ダークの body の文字）は主として扱う。`gray-50` に寄せるかは #932 で決める
     - `gray-400`（Solid Gray 420）は、面によらずダークモードの文字に使わない（`gray-800` に対して 4.17）
  3. **法務・知財担当への確認**：unslop（CC BY 4.0）を訳して公開リポジトリに置いたことの表記が足りているかを確かめる。問い合わせはオーナーが送る（文案は #930 に置いた）
  4. **情報システム部門への確認**：`.env.local` が本番の DB を指すことのある運用で、画面を Claude に読ませてよいかを確かめる。問い合わせはオーナーが送る（文案は #930 に置いた）。あわせて、開発用の DB を本番と分ける #931 を作った
- **理由**:
  - 1：AI らしい画像（3D の塊・ロボット・文字の焼き込み）は、画面の種類によらず避けたい
  - 2：ライトモードと同じく、ダークモードも DADS のコントラスト（文字 4.5:1）を値で守る。値が無いと、補足の文字が薄くなる（今のコードで `dark:text-gray-400` を文字に使っている所がある。#932）
  - 3・4：組織の規程（知的財産は法務・知財担当へ、個人情報は情報システム部門へ確認する）に沿う
- **却下案**:
  - 1：新しい公開ページだけ（既存の AX サイトの画像を点検できない）。節を削る（新しい公開ページで AI らしい画像を見落とす）
  - 2：今の下限だけ（`text-muted-foreground` より薄くしない）。ダークは対象外
  - 3：確認しない。スキルを外す
  - 4：確認しない。確認だけで Issue を作らない
- **ルール**:
  - ダークモードの文字の色の値は、`.claude/skills/ui-audit/references/dads.md` の「色」に置く。今のコードを合わせる作業は #932
  - 3・4 の回答が来たら、この決定に結果を足す。回答によってスキルを変えるときは、この決定を置き換える
- **参照**: #930、`node_modules/@digital-go-jp/design-tokens/dist/tokens.css`（Solid Gray の値）、`app/globals.css` の `html:has(.dl-admin)`
