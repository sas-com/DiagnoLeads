# AI らしさの兆候

上から順に当て、見つけた兆候を `file:line` と一緒に1行ずつ書き出す。各行は「兆候 → 直し方」。直し方の値は、管理画面では DADS（決定 `2026-10-24-admin-dads`、SKILL.md の「DADS の値」）が先に立つ。公開サイトとビルダーの診断で当てる範囲は、SKILL.md の「対象と優先順位」に従う。共通部品で見つけた兆候は直さず、Issue に切り出す。

兆候ではないもの：Tailwind の段階の余白（`gap-1.5` などの 0.5 刻み）、DADS のフォーカス（黒の outline と黄色）、日本語の見出しの 0.01〜0.02em の字間、略語の大文字、読み込み中の `Skeleton`・スピナー・進み具合の棒、AX サイトの `ax-*` の色・`rounded-full` のボタン・見出しの上の小さなラベル。

## 面と色

- 背景・カード・ボタン・選択中のメニューに、紫から青・紫からピンクのグラデーション → 1色の面。アクセントは意味のある所だけ
- 見出し・数字・ロゴにグラデーションの文字 → 主の文字色の単色
- 色つきの発光（`shadow-[0_0_20px_rgba(139,92,246,0.5)]`、絵文字の `drop-shadow`、光る錠剤形のバッジ） → 消す。奥行きは面の段階と細い枠線で
- 中身の後ろの放射状の色のにじみ・ぼかした塊 → 消す
- ネオンや濃い色の枠線 → 細い枠線（Solid Gray）
- 同じ色相のほぼ同じ色を何段も文字に使う（薄紫が5種類など） → 主 `gray-900`・補足 `gray-600`〜`gray-700`・控えめ `gray-500` の3つの役割（`gray-500` より薄い色を文字に使わない）
- 全部が強調されて、何も目立たない → アクセントは1画面に1〜2か所
- 白い内側のハイライトと色つきの影のすりガラスのカード → 枠線つきの普通の面

## 文字

- 太さ 500・600・800・900 → 400 か 700 に寄せる。見出しと強調は 700（DADS のトークンは 400 と 700）
- 英語の大文字で `tracking-wider` 以上の字間のラベル（`NAVIGATION`・`PAID THIS MONTH`） → 普通の書き方（日本語のラベルなら日本語に）。略語（CSV・AI・AX・KPI・URL・ID）はそのまま
- 1画面に大きさと太さが多すぎる → 段階から少数だけ
- 数字の書式がばらばら（`¥48,210` の隣に `¥124,860.40`、`07`） → 書式を1つに、`tabular-nums`
- 小さい文字に負の字間 → 0 か少し広め
- 強調に斜体 → 色か太字 700
- 14px 未満の文字・14px の本文 → 本文は 16px 以上、14px は補足だけ（DADS）

## アイコン

- メニュー・ラベル・状態に絵文字（🏠 📥 🚀 💰 ⚠️ 📈 🔥） → lucide-react の線のアイコンか、無し
- 錠剤形のバッジや件数の中の絵文字（`18 👤`） → 数字だけ
- アイコンの大きさと色がばらばら → 大きさと線の太さを1種類に、色は文字の役割
- アイコンが列からずれる → 各行でアイコンの箱の幅を同じに
- AI の機能に必ず付く ✨ → 消すか、説明になる所だけ普通のアイコン

## 余白

- Tailwind の段階に無い任意値（`mt-[13px]`・`ml-[7px]`・`h-[31px]`） → 段階の値
- 同じ一覧の中で行の高さや間がばらばら → 高さと間を1つに
- グループが、自分の項目より隣のグループに近い → グループの中は狭く、グループ同士は広く
- 並んだカードの内側の余白がばらばら → 1つに
- 節の上に大きな空き、下が窮屈 → 釣り合いを取る

## 文言

- 挨拶の見出し（「おかえりなさい、〇〇さん！👋」） → ページの名前か期間（「2026年11月」）
- 感嘆符（「！」「!!」） → 普通の文
- 比べる相手の無い増減（「+12%!!」「3件減!!」） → 「前月比 +12%」「前月より3件少ない」（比べる相手は見える文字で。`sr-only` だけにしない）
- 長いプレースホルダー（「なんでも検索…」） → 「検索」
- 宣伝の言葉（「劇的に」「シームレス」「魔法のように」「革新」「AI 搭載」） → 実際に何をするか
- ラベル・ボタン・見出しの文末の「。」 → 付けない
- 作り物らしいデータ（連番の数字、「[X]」「サンプル太郎」） → 架空と分かる社名・人名、`example.com`、実在しない電話番号、偏りのない数字。実在の会社名・人名・個人を指すデータは使わない
- 画面にじかに書いた文字列 → `locales/`（ja・en）に移す

## 部品

- 件数・プラン・ショートカット・状態の光る錠剤形のバッジ → 控えめの文字か、キーキャップ
- どこにでもある `PRO`・`NEW ✨`・`Beta 🚀` → 消すか、控えめの文字のバッジを1つ
- 検索・ボタン・カードの全部が丸い錠剤形 → 大きさに合わせた DADS の段階の角丸、内と外の角丸を合わせる
- 虹色の棒・光る棒・丸い棒・英語の大文字の曜日のグラフ → 色は1〜5色（DADS）で強調は1つ、目盛りは控えめに
- どのグラフもアクセントの濃淡だけで、どれも目立たない → ほかは `gray-400` 以上の灰色（背景と 3:1 以上。`components/charts/` の部品で CSS 変数の値を渡す）にし、アクセントは大事な1つだけ。系列は線の形・点の形・凡例の文字でも区別する（色だけで区別しない）
- 数字のカードごとにミニグラフ・小さな棒・アイコン → ラベル・数字・比べる相手を書いた増減だけ
- 同じ幅のカードに同じグラフを並べる → 主なグラフを1つ、数字のカードは小さく、幅に強弱
- グラフのグラデーション・3D・影、データの更新日が無い、棒の原点が 0 でない → 単色、更新日を書く、原点 0（DADS のガイドブック）
- 塗りのボタンが1画面に複数 → 主な操作だけ塗り、ほかは枠線か文字のボタン（DADS）
- グラデーションのタイルに ✨ のロゴ、グラデーションの文字のロゴ → 製品の名前の文字と、単色の簡単なマーク

## 公開ページとヒーロー（AX の公開サイト）

AX の公開サイトで直すのは、絵文字・根拠のない主張・宣伝の言葉だけ。配置・色・ボタンの形は決定 `2026-10-11-ax-diagnosis-v2` のまま。文言を変える前にオーナーに確かめる。下の配置の兆候は、新しく作る公開ページで使う。

- 見出しの上の錠剤形のバッジ（「✨ 新しくなりました」） → 消すか、本当の知らせなら控えめの文字のリンク
- どの製品にも当てはまる見出し（「AI で業務を劇的に変える」） → この製品が誰に何をするかを、この製品の言葉で
- 見出しのグラデーション・光る動き → 単色
- ヒーローの後ろの浮いた塊・光る格子や線 → 無地か、製品の本物の画面1つ
- 3つ以上のボタン、ボタンの下にチップやアバターを積む → 主な操作1つと、副の操作を1つまで
- 出どころの無い「1万社が利用」・星5つ・アバターの列 → 本当かを確かめ、具体的にするか消す
- 絵文字・太字の題・あいまいな1行のカードの羅列 → 数を減らし、具体的な文言と線のアイコン（か無し）

## 画像

- つやのある 3D の塊・球・液体金属・紫の星雲 → 製品そのものか、何をするかを表す具体的な1つ
- AI を表すロボット・光る脳・回路の線・ホログラム → 消すか、AI が実際に出すものを見せる
- 文字・偽のボタン・偽のロゴを焼き込んだ画像 → 文字はページの文字に
- どの節にも画像 → 役に立つ所に1つだけ

## 動き

- 生きていない飾りの `animate-pulse`・`animate-ping`・明滅する光 → 止める。読み込み中の `Skeleton`・スピナー・進み具合の棒は残し、`motion-reduce:` で止まるようにする
- カードやボタンの `transition-all`・`hover:scale`・`active:scale` → ホバーと押下は色か面の段階の変化だけ
- はねる・行き過ぎる動き → 1つの ease-out
- 読み込み時に全部が別々の方向から飛んでくる → 主な中身の短いフェードと小さな上昇を1回だけ
- 視差・浮遊のループ・スクロールで動く要素 → 動かさない
- 幅・高さ・top・left のアニメーション → transform と opacity

## ひな形の見た目

兆候ではないが、整えたあとに誰も判断しないと落ち着く見た目。層を当てたあとに確かめる。

- 見出しが、製品の名前を替えても別の製品に通じる → この製品の言葉で、何をするかを書く
- 注目させる所が無く、全部が同じ灰色のカード → 主なグラフか大事な数字を1つ決め、そこにだけ色と手間をかける
- どの画面も同じ配置 → 画面の目的（一覧・詳細・分析）に合わせて強弱を変える
