# ui-audit：画面の「AI らしさ」を点検して直す

unslop（Damir Sokolovsky、[@heydamir](https://x.com/heydamir)、[heydamir/unslop](https://github.com/heydamir/unslop/tree/a6f121eee5f29c2f74976b75456feae8b66afb3a)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）の考え方と兆候の一覧をもとに、日本語に訳し、このリポジトリの決定に合わせて書き直したもの（太さ・書体・色・画像・動画の決まりを変えた・省いた）。作者の表記はこのファイルと [references/signs.md](references/signs.md) に残す（ライセンスの条件）。

考え方：AI らしい画面は、色と装飾を枠（背景・ボタン・枠線・ラベル）に広げる。デザインされた画面は、枠を静かにし、色を「注目してほしい1〜2か所」（大事な数字、今月の棒、選んでいる行）にだけ置く。機能・中身・節の順番は変えず、大きさ・色・言葉を1つずつ意図のあるものにする。

## 優先順位

このスキルの決まりより、次の決定が先に立つ。食い違ったら決定に従い、unslop の流儀に寄せない。

| 対象 | 従う決定 | 要点 |
|---|---|---|
| 管理画面（`app/[locale]/(dashboard)/`・`components/ui/`・`components/studio/`・`components/layout/`）と認証画面 | `2026-10-24-admin-dads` | 色は DADS Green と Solid Gray。本文 16px 以上（14px は補足だけ）、行間 1.5 以上、強調は太字 700、リンクは下線。塗りのボタンは1画面に原則1つ、押せる範囲 44px 以上。影は重なる部品だけ。フォーカスの色は変えない |
| グラフ | `2026-10-24-chart-library-apexcharts`・`2026-10-24-admin-dads` | ApexCharts だけ。グラデーション・3D・影なし、色は1〜5色、棒の原点は 0、データの更新日を書く、色だけで区別しない |
| AX の公開サイト（`components/features/ax-site/` など） | `2026-10-11-ax-diagnosis-v2`・`2026-10-26-ax-device-font-on-mobile` | 書体と色はそのまま。兆候の除去と文言だけを当てる |
| 部品 | `2026-10-09-ui-modern-components` | shadcn/ui（`components/ui/`）を使う。アイコンは lucide-react |
| 文言 | CLAUDE.md | 画面の文字列は `locales/`（ja・en）に置く。ja と en を両方直す |
| ヘルプ | `2026-10-28-in-app-help` | 画面の見た目や名前を変えたら、`lib/features/help/` の記事も直す |

unslop から**持ち込まないもの**：書体の変更、太さの上限 600、独自の色のランプとアクセント、画像の生成、動画（story）、ライブサイトの取り込み（Playwright・ffmpeg・有料サービスが要る）。

## 手順

1. **画面を見る**：その画面を描くファイルを探す。動かせるなら開いてスクリーンショットを撮り、見えている姿で判断する（スキル `run`）。撮れなければコードから判断し、報告にそう書く
2. **点検**：[references/signs.md](references/signs.md) を上から順に当て、見つけた兆候を1行ずつ `file:line` と一緒に書き出す
3. **程度を決める**
   - 多い（色・文字・アイコン・文言にまたがる）：下の層を全部当てる
   - 少ない（ほぼ整っていて、数か所だけ）：見つけた所だけ直す。大きな案は報告の「提案」に回す
   - 無い：そう言って、直す候補を値つきで2〜3個まで出し、頼まれたときだけ当てる。良い画面を、違いを出すために変えない
4. **確認して止まる**：点検の結果と、注目させる所（1〜2か所）をオーナーに見せ、返事を待ってから編集する。「そのまま直して」と言われていれば待たない
5. **層ごとに直す**：1つの層を画面全体で終えてから次へ進む（下の表の順）
6. **確かめる**：最後のチェックリストを当て、もう一度見て、点検の一覧に残りが無いことを確かめる。関係するテスト（`bunx vitest run <path>`）と `bun run typecheck` を流す
7. **報告**：層ごとに何を変えたかを数行で。残した兆候と理由、提案も書く

## 層（この順に直す）

| 順 | 層 | 直すこと |
|---|---|---|
| 1 | 余白 | 4px の倍数にそろえる（`mt-[13px]` のような半端な値を消す）。同じものは同じ大きさ。グループの中の間は、グループ同士の間より狭く。アイコン・ラベル・数字は1本の列にそろえる |
| 2 | 色 | 背景・面・枠線・文字は Solid Gray から。文字の役割は主・補足・控えめの3つ。アクセント（Green）は主な操作・選択・一番大事な数字だけ。意味の色（成功・エラー）は意味があるときだけ。色相をまたぐグラデーション・グラデーションの文字・色つきの発光と影・背景のぼかしの塊・ネオンの枠線を消す |
| 3 | アイコン | 絵文字のアイコン・飾りを lucide-react の線のアイコンにするか、消す。大きさと線の太さを1種類に。色は文字の役割に合わせ、アイコンごとの色を付けない |
| 4 | 文言 | 下の「日本語の文言」。文言は大きさと配置を決めるので、文字と配置より先に直す |
| 5 | 文字 | 大きさは段階から少数だけ。階層は大きさと色で付け、太字 700 は強調だけ。英語の大文字のラベル（`NAVIGATION`）と広い字間をやめる。数字は `tabular-nums` で、書式を画面の中でそろえる（桁区切り・小数の桁・単位）。斜体で強調しない |
| 6 | 配置 | 節と順番は変えない。同じ幅のカードを同じ中身で並べるだけの形を避け、大きいもの（主なグラフ）と小さいもの（数字のカード・一覧）で強弱を付ける。塗りのボタンは1つ、ほかは枠線か文字のボタン |
| 7 | 細部 | 角丸は外側から内側の余白を引いた値（4 未満にしない）で、全部を丸い錠剤形にしない。件数や補足は光る錠剤形のバッジではなく控えめの文字に。数字のカードは「ラベル・数字・何と比べた増減」だけで、ミニグラフやアイコンで埋めない。主なグラフを1つ決め、アクセントは大事な系列（今月・追っている線）だけに付け、ほかは灰色の段階に |
| 8 | 動き | 生きていないものの `animate-pulse`・`animate-ping`・光の明滅・浮遊を消す。`transition-all` をやめて `transition-colors` などに絞る。`hover:scale` やはねる動きを消す。幅・高さ・位置を動かさない |

管理画面に画像の生成は使わない。注目させる所は、丁寧に描いたグラフ・整った数字・本物に見える中身で作る。

## 日本語の文言

unslop の英語の決まりを、日本語の画面向けに直したもの。

- 挨拶の見出し（「おかえりなさい、〇〇さん！」）をやめ、ページの名前か期間（「2026年11月」）にする
- 感嘆符（「！」「!!」）を使わない
- 増減には比べる相手を書く：「+12%」ではなく「前月比 +12%」「前月より 3 件少ない」
- 短いラベル：「なんでも検索…」ではなく「検索」。ボタン・見出し・ラベルの文末に「。」を付けない（複数の文の説明文は付ける）
- 宣伝の言葉（「劇的に」「シームレス」「魔法のように」「AI で革新」）をやめ、何をするかを書く。「AI 搭載」を何にでも付けない
- 確かめられない主張（「1万社が利用」「10倍速い」）は、本当かをオーナーに確かめ、本当なら控えめで具体的に、そうでなければ消す。報告に一覧で書く
- 見本のデータは本物らしく（「¥123,456」「[X]」「サンプル太郎」を使わない）。個人を指す本物のデータは使わない
- 「NEW ✨」「PRO」「Beta 🚀」のバッジは、本当に要るときだけ控えめな文字で

## してはいけないこと

- 機能・中身・節の順番を変えない。製品の名前を変えない
- 消した装飾の代わりに別の流行（すりガラス・ノイズ・ネオン・ベントーグリッド）を足さない
- 機能・主張・データを作らない
- DADS の値（色・本文の大きさ・太さ・フォーカス・押せる範囲）を、見た目のために崩さない

## チェックリスト

- [ ] 余白が 4px の倍数で、同じものが同じ大きさ
- [ ] アイコン・ラベル・数字がそれぞれ1本の列にそろう
- [ ] 色は Solid Gray と Green（AX の公開サイトはそのサイトの色）。アクセントは1〜2か所
- [ ] 色相をまたぐグラデーション・グラデーションの文字・発光・色つきの影・ぼかしの塊が無い
- [ ] 絵文字が残っていない。アイコンは lucide-react で、大きさと線の太さが1種類
- [ ] 本文 16px 以上、英語の大文字のラベルが無い、斜体の強調が無い
- [ ] 感嘆符・挨拶の見出し・比べる相手の無い増減・確かめていない主張が無い
- [ ] 数字の書式がそろい、`tabular-nums`
- [ ] 角丸が内と外で合う
- [ ] グラフにグラデーションが無く、色は1〜5色、更新日がある
- [ ] 繰り返す動き・はねる動き・`transition-all` が無い
- [ ] 文言は `locales/` の ja と en の両方にある。画面の名前や見た目を変えたら、ヘルプの記事も直した
- [ ] ひな形の確認：製品の名前を別の製品に替えても通じる画面なら、文言と注目させる所を、この製品の言葉と中身にもっと寄せる
